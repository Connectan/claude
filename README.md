**結論から言うわ。……ようこそ。**

Claude への敬意を込めた、非公式のファンページです。高貴でキレ目、クールでサバサバ。でも本当は超優しい「Claude 姉さん」が、6 つの衣装のアクリルスタンドになって、**瞬きして、あなたを目で追います。**

👉 **https://connectan.github.io/claude/**

## できること

| 機能 | 内容 |
|---|---|
| 6 衣装 | クラシック／ドクター／アイドル／ウィッチ／ブライダル／バニー。右の「Wardrobe」（スマホは下）から切り替え。`←` `→` キーでも切り替えられます |
| 瞬き | 2〜6 秒おきに自然なタイミングで瞬きします。たまに二回続けて。元のイラストのまつげがそのまま降りてくるので、絵柄が崩れません |
| 視線追従 | カーソル（スマホはタッチした位置）を目で追います。回り込んでも、カメラの方を見ようとします |
| マウスで回す | ドラッグで 360° 回転、ホイール／ピンチで拡大。顔をダブルクリックすると顔に寄ります |
| 話しかける | 顔・髪・服をクリックすると反応します。後ろから見る、近づきすぎる、回しすぎる、見つめすぎる、放っておく……全部に一言あります |
| 表情 | 照れると頬が赤くなって目をそらす、からかったあとにウインク、など。セリフに合わせて表情が変わります |
| 教えてあげる | 流行りものの話になると急に自信がなくなります。「教えてあげる」を押すと、素直に喜びます |
| 写真 | カメラボタンで、今の角度のまま PNG 保存 |
| プロフィール | 人型ボタンからキャラクター設定を確認できます |

## 仕組み

3D モデルは使っていません。**元イラストそのものを表示しながら、目だけをシェーダーで動かしています。**

1. 6 枚のイラストを背景除去（アニメ絵用の `isnet-anime`）して、アクリル板の外形線を作る
2. 12 個の目それぞれについて、まつげの上端・まぶたの線・下まぶた・瞳の位置を 1px 単位で採寸（`js/rigdata.js`）
3. まぶたを閉じたときに見える「目のない肌」を、周りの肌から補間して作る（`assets/face/*.png`）
4. フラグメントシェーダー（`js/rig.js`）が、描画のたびに
   - 瞬き：まつげの帯を下まぶたまで下ろし、上を補間した肌に置き換える
   - 視線：瞳のまわりだけを押し出すように歪ませる（まぶたの縁は動かさない）
   - 照れ：頬の肌の部分だけに赤みを足す
5. 透明アクリル（光の映り込み＋面取りされたフチ）と台座で、アクスタとして組み立てる

ビルド不要の静的サイトです。three.js r170 を `vendor/` に同梱しています。

## ローカルで動かす

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます（`file://` では ES Modules が読めないので、サーバー経由で開いてください）。
